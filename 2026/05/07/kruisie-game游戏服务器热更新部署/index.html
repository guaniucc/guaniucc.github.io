场景: 游戏服务器需要支持热更新，减少对在线玩家的影响
挑战: 晚上连接数高，早上连接数低，传统更新方式影响用户体验
解决方案: 使用 Krusie-Game 实现游戏服务器的热更新和优雅重启

环境要求

Kubernetes 集群要求

  • Kubernetes 版本: v1.18+
  • 推荐版本: v1.20+
  • 集群节点: 至少 3 个节点（生产环境建议）

资源要求

  • CPU: 每个节点至少 2 核
  • 内存: 每个节点至少 4GB
  • 存储: 支持动态 PV 供应

网络要求

  • CNI 网络插件（Calico、Cilium、Flannel 等）
  • 确保节点间网络通信正常

指标 监控方式 告警阈值 说明
