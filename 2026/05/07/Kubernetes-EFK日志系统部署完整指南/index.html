🎯 EFK 概述

什么是 EFK

EFK 是 Elasticsearch、Fluentd、Kibana 的缩写，是 Kubernetes 集群中最常用的日志收集和分析解决方案：

  • Elasticsearch: 分布式搜索和分析引擎，用于存储和索引日志数据
  • Fluentd: 统一的日志收集层，负责收集、过滤和转发日志
  • Kibana: 数据可视化平台，提供日志搜索、分析和展示界面

EFK vs ELK

组件 EFK ELK
日志收集器 Fluentd Logstash
性能 更高，资源占用更少 相对较低，资源占用较多
配置复杂度 简单，基于配置文件 较复杂，需要更多配置
Kubernetes 集成 原生支持，配置简单 需要额外配置
社区支持 CNCF 毕业项目，云原生友好 成熟稳定，企业广泛使用

核心优势

  1. 统一日志收集: 集中管理所有容器和节点的日志
  2. 实时搜索: 快速搜索和分析海量日志数据
  3. 可视化分析: 丰富的图表和仪表板展示
  4. 可扩展性: 支持水平扩展，处理大规模日志数据
  5. 多数据源: 支持多种日志格式和数据源

整体架构

数据流向

  1. 日志收集: Fluentd DaemonSet 在每个节点上运行，收集容器日志和系统日志
  2. 日志处理: Fluentd 对日志进行解析、过滤和格式化
  3. 日志存储: 处理后的日志发送到 Elasticsearch 集群进行存储和索引
  4. 日志展示: Kibana 连接 Elasticsearch，提供搜索和可视化界面

组件 CPU 内存 存储 副本数
Elasticsearch 2-4核 4-8GB 100-500GB 3
Fluentd 0.5-1核 1-2GB 10-50GB 每个节点1个
Kibana 1-2核 2-4GB 10GB 2
